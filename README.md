# 🎰 Казино «Путь»

Браузерная игра-казино в одном HTML-файле. Вы проходите цепочку из **10 домов**, в каждом — случайная азартная мини-игра. Цель — дойти до конца и приумножить стартовый капитал. Потеряете все деньги раньше — тюрьма.

---

## 🚀 Быстрый старт

Никаких зависимостей и сборки не нужно.

1. Скачайте файл `index.html` (или `casino.html`).
2. Откройте его двойным щелчком в любом современном браузере.
3. Играйте.

Работает офлайн, весь код — в одном файле.

---

## 🎮 Правила игры

- **Стартовый капитал:** 5 000 ₽
- **Минимальная ставка:** 100 ₽ (если денег меньше — можно поставить всё)
- **Домов на пути:** 10
- **Каждый дом посещается один раз** — зайти повторно нельзя
- **Цель:** дойти до конца и обогатиться (заработать больше 5 000 ₽)
- **Проигрыш:** если капитал упадёт до нуля до финиша — тюрьма 🚔

Перед каждой игрой вы сами выбираете сумму ставки:
- ползунком,
- кнопками быстрых ставок (100 / 500 / 1000),
- кнопкой **«ВА-БАНК»** (ставит всё).

## 🎲 Мини-игры

В каждом доме случайно выпадает одна из пяти игр.

### 🪳 1. Тараканьи бега

Вы и три таракана наперегонки идёте к 30-й клетке. Каждый ход все бросают шестигранный кубик и двигаются на выпавшее число. Кто первый дошёл — победил.

- **Победа:** выплата **×3**

### 🃏 2. Очко 21

Поле 6×6 заполнено картами от 2 до 11. Бросок двух кубиков определяет строку и столбец — вы открываете карту. Набирайте сумму до 21, но не больше.

- Дилер останавливается на **17 и более**
- **Победа:** ×2, **ничья:** возврат ставки, **перебор:** проигрыш

### 🎰 3. Автомат

Три столбца по 6 ячеек: 3 🍒, 2 🍉, 1 семёрка. Кубик выбирает позицию в каждом столбце.

| Комбинация | Множитель |
|---|---|
| 🍒🍒🍒 | ×2 |
| 🍉🍉🍉 | ×5 |
| 7️⃣7️⃣7️⃣ | ×10 |

### 🎯 4. Дартс

5 ходов. Каждый ход — бросок двух кубиков, числа перемножаются. Максимум за 5 ходов — 180.

| Очки | Результат |
|---|---|
| 111+ | **×6** |
| 85–110 | **×2** |
| 60–84 | возврат ставки |
| меньше 60 | проигрыш |

### 🎡 5. Рулетка

Бросок двух кубиков, числа перемножаются — выпадает число от 1 до 36. Делайте ставку:

- на 🔴 красное или ⚫ чёрное — **×2**
- на точное число — **×8**

**Красные числа:** 1, 2, 4, 6, 8, 10, 12
**Чёрные числа:** 3, 5, 9, 15, 16, 18, 20, 24, 25, 30, 36

## 🛠️ Технические детали

- **Стек:** чистый HTML + CSS + JavaScript (vanilla), без библиотек
- **Один файл** — `index.html`
- **Размер:** ~30 КБ
- **Совместимость:** Chrome, Firefox, Edge, Safari (последние версии), работает на мобильных
- **Данные:** игра не сохраняется — при перезагрузке страницы прогресс сбрасывается
